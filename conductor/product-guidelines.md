# Product Guidelines: MyPTV Enhancement Suite

## Core Philosophy
- **Precision First**: Calibration and analysis must prioritize sub-pixel accuracy and mathematical rigor.
- **Researcher-Centric**: Tools should automate tedious tasks while providing clear, peer-reviewed justifications for all calculations.
- **Reproducibility**: All analysis protocols must be documented and repeatable.

## Engineering Standards
- **Pythonic Code**: Follow PEP 8 guidelines.
- **Mathematical Integrity**: Use LaTeX in docstrings to document equations and cite peer-reviewed sources.
- **Test-Driven**: Core mathematical logic should be verified with unit tests.
- **Modular Design**: Keep UI, calibration logic, and analysis suites separate and extensible.
