# Note Categories

This file defines the bins and categories for organizing notes in this workspace.

- **Progress**: Tracking the current status, milestones, and ongoing tasks of the project.
- **Experiment Knowledge**: Observations, insights, and lessons learned from the physical experimental setup (lighting, hardware, environment).
- **Data Processing Knowledge**: Observations, insights, and strategies related to data analysis, algorithms, and software workflow (segmentation, matching, etc.).
